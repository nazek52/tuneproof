# XERJ Corpus Hub selection

In November 2026, **[XERJ](https://github.com/xerj-org/xerj)** selected **[TuneProof](https://github.com/nazek52/tuneproof)** for inclusion in its Corpus Hub, a reference-code index for coding agents.

The selected work is the CPU LoRA experiment, leakage-aware data preparation, tests and measured evidence. XERJ's selection notice identified the implementation commit titled `feat: add real CPU LoRA lab, leakage-aware bundles, 84 tests and measured evidence`.
